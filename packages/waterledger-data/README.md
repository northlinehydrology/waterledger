# waterledger-data

Public U.S. water data for any place, fetched once and cached, as used by [Water Ledger](https://waterledger.org):
Census cities and townships, EPA water system service areas, USGS watersheds, EPA ATTAINS impaired waters, EPA ECHO and
CWNS sewer plants, NOAA hourly weather and Atlas 14 design storms, and EIA electric utilities.

Downloads are cached under `WATERLEDGER_CACHE` (default `~/.cache/waterledger`) or the `cache` path in a `waterledger.toml`.
